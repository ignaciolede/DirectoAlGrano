# ReviewField

Campos de texto: el área de la review, inputs de una línea y el buscador redondo.

**Qué provee quien lo usa:** el `<label>`, el placeholder y el contador.

- `dag-textarea`: mínimo 132px, crece hacia abajo; placeholder en voz de la marca ("Contalo sin vueltas").
- `dag-input`: 48px, para "¿Qué comiste?" o el nombre de una cafetería nueva.
- `dag-search`: pastilla de 48px para buscar cafeterías o direcciones (ubicación).
- Fuente 16px siempre: evita el zoom automático de iOS.
- Foco: borde `brand` más anillo `focus`.
