# Icons

Set propio de 21 íconos lineales: grilla 24px, trazo 1,75, puntas y uniones redondeadas. Los SVG vienen en tinta `ink` (#24170f) para `<img>`; en la interfaz usalos inline con `DirectoAlGrano.icon(nombre)` o `<span data-icon="nombre">`, que toman `currentColor`.

| Ícono | Uso |
| --- | --- |
| `bean` | El grano de la marca; unidad de los aspectos 1–5 |
| `ranking`, `map`, `wishlist`, `journal`, `plus` | Tab bar |
| `cup`, `place`, `service`, `price`, `laptop` | Aspectos: Café, Lugar, Atención, Precio/calidad, Para trabajar |
| `food` | ¿Comiste? |
| `search`, `filter`, `route`, `back`, `more`, `edit`, `check`, `calendar`, `crown` | Acciones y estados |
